# beadle

Читалка задач [beads](https://github.com/gastownhall/beads) для человека. `bd` владеет
данными, beadle показывает их: список, доска, эпики, связи.

Главное отличие от `beads-ui`, Beadbox и perles: **активный проект живёт в адресе
страницы.** Две вкладки с разными проектами не переключают друг друга, ссылкой на
отфильтрованную доску можно поделиться.

## Как запустить

```bash
pnpm install
bun apps/server/src/index.ts add ~/путь/к/проекту
pnpm dev
```

Нужен установленный [`bd`](https://github.com/gastownhall/beads) — данные beadle
берёт только у него. Реестр проектов — список путей в `~/.config/beadle/workspaces.json`;
сервер сам добавит в него проект, из каталога которого его запустили.
Сервер слушает 4200, фронт — 4201 и проксирует на него `/api`.

Один исполняемый файл — `pnpm binary`: собирает фронт и вшивает его в бинарь
рядом с сервером. Дальше `./beadle` из любого каталога, всё на одном порту.
Готовые бинари под macOS и Linux — в [выпусках](../../releases).

## С телефона

Сервер слушает только `127.0.0.1` — снаружи его нет. Чтобы открыть с телефона
в своей сети:

```bash
./beadle --host 0.0.0.0
```

Он напечатает адрес, который набирают на телефоне, и предупреждение. Оно по делу:
**пароля у читалки нет**, и любой в этой сети увидит задачи всех проектов реестра
и пути к ним на диске. Дома — нормально, в кафе и коворкинге — нет; туда лучше
пробросить порт через ssh (`ssh -L 4200:127.0.0.1:4200 …`) или завести общую
частную сеть.

## Устройство

```
apps/server/     Hono на bun; данные — только через CLI bd
apps/web/        Vite + React + TanStack Router, стили на vanilla-extract
packages/protocol/  Zod-схемы, выведенные из живого вывода bd list --json
```

Правила работы — `CLAUDE.md`. Что менялось — `CHANGELOG.md`.
Документация и комментарии по-русски: это инструмент для себя, а не библиотека.
